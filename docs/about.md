# Über dieses Projekt

**Ziel:** In **2–3 Minuten** einen **privaten Schuldschein** als PDF erstellen – kostenlos, anonym, ohne Server.  
Ich habe leider mehrfach erlebt, dass die **Zahlungsmoral im Freundeskreis** ohne schriftliche Vereinbarung leidet. Dieses Tool soll helfen, die Dinge fair und klar zu regeln.

## Idee & Ansatz
Der Generator ist bewusst **simpel** gehalten – sowohl in der Nutzung als auch im Code.  
So können auch **Programmieranfänger** alles nachvollziehen.

- **Stack:** Vanilla **JavaScript**, **Tailwind CSS**, **jsPDF**, **HTML5**  
- **Client-only:** Keine Speicherung, keine Cookies, **keine Serverkommunikation**. Alles läuft im **Browser**.  
- **Open Source:** GitHub-Repo → <https://github.com/michaelblaess/schuldschein-generator>

## Was du bekommst
- Formular ausfüllen → **Live-Vorschau** → **PDF herunterladen**  
- Optional: **Zeugenfeld**, **anpassbarer Dokumenttitel**, **Wasserzeichen**  
- Automatik: **Fälligkeit** (Vertragsdatum + Laufzeit), **IBAN-Plausibilitätscheck**, **Betrag in Worten**

## Rechtliche Hinweise
- Dieses Tool stellt **keine Rechtsberatung** dar. Nutzung auf eigenes Risiko.  
- „Schuldschein Generator“ ist **kein eingetragenes Warenzeichen**.  
- Keine Verbindung zu **Finanzdienstleistern, Banken oder Rechtsberatern**.  
- Prüfe das Dokument vor Verwendung und **lasse es im Zweifel juristisch prüfen**.
